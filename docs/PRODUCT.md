# 产品范围

更新：2026-10-16。StillEnough 在 Windows 桌面集中展示真实来源的 AI 额度、重置时间与 API 余额。连接配置是输入，指标是只读查询结果。

## 当前能力

添加账号 → 配置 API 凭据或授权 CLI 登录来源 → 测试读取 → 核对账号并启用保存。支持范围与实测门槛统一见 [平台说明](PROVIDERS.md)。

主窗口展示账号、独立额度窗口或余额、来源、更新时间与采集状态。未知、过期、无权限、接口变化分别呈现；断网保留旧值和原时间，到重置点不自动恢复 100%。不汇总不同币种，不用本地 token 数推算官方余量，不提供人工额度或演示数据。

浮窗支持关注账号、单列排序列表、拖动手柄或上移/下移排序、恢复自动排序；默认显示 4 个，可选 1–8 个。支持别名、进度条、重置时间开关、透明度、折叠、置顶、关闭与位置恢复。主窗口与浮窗共享后台状态。

## 采集、历史与提醒

自动采集默认每 10 分钟，可选 5/10/15/30 分钟；支持全局暂停与账号停用。手动刷新跳过自动间隔，但遵守防抖与平台限流。网络支持全局设置及账号覆盖，CLI 来源有独立限制。

低额度默认提醒线 30/20/10/5%，可调整并按账号、窗口与周期去重；过期和未知值不提醒。当前只有应用内提醒，未接入 Windows 系统通知。钱包余额不套用百分比提醒。

历史提供 7/30 天曲线，保留期可选 30/60/90 天、默认 90 天；按重置分段，缺口不插值。JSON/CSV 导出目前包含账号与当前指标，不是完整历史序列。支持删除账号及清理本工具数据。导出不含凭据、认证路径或原始响应。

## 数据与兼容

API 凭据存系统凭据库，SQLite 保存连接引用、设置与观测。CLI 来源须授权，只读使用 access token 或通过官方 CLI 查询，不改写认证文件或抢占 refresh token。

旧计费/人工记录通过历史迁移清理；迁移文件必须保留，不能为首次开源重新编号或合并。应用目录和凭据服务标识保持兼容。

## 验证

读取成功至少需要一个有效真实指标，HTTP 200 或认证通过不足以证明额度读取成功。单个账号成功不代表全部地区、套餐和窗口已验证。

实现及自动测试与真实账号、Windows 验收分别记录。新版浮窗显示/排序、关于页、安装卸载、多屏 DPI、睡眠恢复与平台对照仍需验证，见 [当前待办](../TASKS.md)。
