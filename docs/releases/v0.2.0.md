# StillEnough v0.2.0

发布日期：2026-10-17。

## 新增与改进

- 支持简体中文和 English，在设置页选择跟随系统或指定语言，偏好保存在本机。主窗口、浮窗及托盘使用相同语言设置。
- 覆盖连接说明、渠道名称、历史指标、提醒、错误状态和日期时间。未知币种显示为当前语言的提示，保留来源金额和精度。
- 主窗口左侧导航及顶部标题栏固定，右侧内容独立滚动；切换页面后返回顶部。
- 滚动条改为细圆角滑块与透明轨道，颜色适配深浅主题，悬停时加深。
- 修复托盘显示/隐藏提示、浮窗原生菜单与后台状态同步。

## 下载与升级

下载 `StillEnough-v0.2.0-windows-x64.zip`，解压后运行 `StillEnough.exe`。需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。

升级前从托盘退出旧版，再解压新版到独立目录运行。保留现有应用数据目录与系统凭据服务标识，不修改其他 CLI 的认证文件。`SHA256SUMS.txt` 提供 ZIP 文件校验值。

## 验证与已知限制

- 版本一致性、版本脚本测试、TypeScript、ESLint、36 项前端测试、前端生产构建与 Rust fmt/clippy 检查通过。
- 新增语言字段兼容、序列化和 SQLite 恢复测试通过。Rust 全量测试 92 项通过、1 项失败、7 项忽略；失败为已记录的百炼 CLI 子进程用例（`child_success_failure_timeout_and_output_limit` / `cli_query_failed`），不宣称全量测试通过。
- 本次构建使用本地已安装依赖；项目指定 pnpm 的版本切换仍存在锁文件权限问题，未验证干净目录依赖安装。
- 本版未完成原生窗口同步、干净 Windows、多屏/DPI、睡眠恢复及全部平台套餐/区域对照。未新增真实账号验证，不改变适配器实验性状态。

平台来源与验证范围见 [平台说明](https://github.com/com1com4/StillEnough/blob/v0.2.0/docs/PROVIDERS.md)。
