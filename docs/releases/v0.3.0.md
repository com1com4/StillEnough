# StillEnough v0.3.0

发布日期：2026-10-18。

## 新增与改进

- 新增独立 CLI，可供终端和 AI Agent 调用：version、providers、accounts list、quota、refresh、operations get、doctor；支持 JSON、超时和明确退出码。
- GUI 与 CLI 共用桌面后台，通过 Windows 命名管道查询和刷新；CLI 不读取凭据、不直接连接厂商接口。桌面关闭后的只读缓存访问需要单独授权。
- 设置页增加 CLI / AI Agent 访问、刷新和离线缓存三个权限开关，默认全部关闭，只能在主窗口开启。
- 账号状态与指标新鲜度分开；未知值保持未知，钱包百分比为 null，过期观测保留原时间。
- 设置页复选框改为圆形滑块开关，支持深浅主题、键盘焦点和禁用状态。

## 下载与升级

下载 `StillEnough-v0.3.0-windows-x64.zip`，完整解压后运行 `StillEnough.exe`；同目录的 `stillenough-cli.exe` 用于命令行。本次只发布便携 ZIP 和 SHA256 校验文件，不发布安装程序、独立 CLI ZIP 或 npm 包。

需要 Windows 10/11 x64、Microsoft Edge WebView2 Runtime；本地 CLI 构建依赖 VC 运行库，干净 Windows 兼容性仍待验证。升级前从托盘退出旧版，解压新版到独立目录；保留现有数据目录与系统凭据存储位置。

```powershell
.\stillenough-cli.exe version --json
.\stillenough-cli.exe providers
# 在主窗口设置中开启 Agent 访问后：
.\stillenough-cli.exe quota --json
```
