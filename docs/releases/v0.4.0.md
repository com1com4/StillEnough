# StillEnough v0.4.0

发布日期：2026-10-19。

## 新增与改进

- 浮窗新增“闲置时淡化”，默认开启。闲置不透明度可在 1%–100% 调整，默认 10%；鼠标移入或键盘操作时恢复原设置的不透明度，移出后平滑淡化。设置保存到本机，重启保留。
- 移除遮挡额度的右上角悬停按钮组，不增加底部操作条。拖动左侧平台图标、名称或别名即可移动浮窗，右侧额度仍可点击打开主窗口；刷新、折叠、置顶、隐藏及退出统一使用右键菜单，Escape 可隐藏。
- 自 v0.3.0 起新增 MiniMax 海外 API/Token Plan、GLM 国内/海外 Coding Plan、Kimi 国内/海外 Code 与 Moonshot API 余额入口，均属实验性、待真实账号验证。订阅额度和 API 钱包余额独立展示；GLM API 钱包因缺少可靠查询契约仍未接入。来源和限制见 [平台说明](https://github.com/com1com4/StillEnough/blob/v0.4.0/docs/PROVIDERS.md)。

## 下载与升级

下载 `StillEnough-v0.4.0-windows-x64.zip`，完整解压后运行 `StillEnough.exe`；同目录包含 `stillenough-cli.exe`。本次发布便携 ZIP 与 SHA256 校验文件，不发布安装程序或 npm 包。

升级前从托盘退出旧版本，再解压运行新版；保留现有本地数据目录与系统凭据库。需要 Windows 10/11 x64、Microsoft Edge WebView2 Runtime 和 VC 运行库。

## 验证边界

版本一致性、版本脚本测试、TypeScript、ESLint、前端 42 项测试与 Vite 构建通过；普通 Windows 用户环境 Rust fmt、工作区 Clippy 和测试通过，7 项真实环境专项忽略。

GUI/CLI release 构建与便携 ZIP 版本、x64 架构、8 文件白名单和逐文件哈希校验通过。

浮窗原生拖动、右键菜单、屏幕边缘、多屏/DPI、重启恢复与长期运行仍待实测；新增地区入口未增加真实账号验证。静态检查和自动化测试不能替代 Windows 交互验收。具体发布检查结果见 TASKS.md。
