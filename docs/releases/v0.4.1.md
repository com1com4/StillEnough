# StillEnough v0.4.1

发布日期：2026-10-20。

## 改进

- 添加账号以平台选择面板替代长下拉框：左侧选择平台，右侧选择产品与地区，支持平台、产品和地区关键词搜索。
- 新增选择摘要和步骤提示；选定后进入连接配置，可返回更换产品。套餐额度与 API 钱包余额继续分开，保留实验性和地区提示。
- 平台列表与产品区域独立滚动，支持深浅主题、简体中文和 English。已有账号直接进入原连接管理流程。

## 下载与升级

下载 `StillEnough-v0.4.1-windows-x64.zip`，完整解压后运行 `StillEnough.exe`；同目录包含 `stillenough-cli.exe`。本次发布便携 ZIP 与 SHA256 校验文件。

升级前从托盘退出旧版本，再解压运行新版。保留现有本地数据和系统凭据。桌面端需要 Windows 10/11 x64、Microsoft Edge WebView2 Runtime 和 VC 运行库。

## 验证边界

版本一致性、版本脚本测试、TypeScript、ESLint、前端 45 项测试与 Vite 构建通过。Rust fmt、工作区 Clippy 通过；普通 Windows 用户环境完整 Rust 测试 127 项通过、7 项真实环境专项忽略。
