# StillEnough v0.4.2

发布日期：2026-10-22。

## 修复

- 浮窗账号行使用行内细焦点框，避免外扩焦点框被滚动容器裁切后显示为账号之间的蓝色横线；保留键盘焦点提示。

## 下载与升级

下载 `StillEnough-v0.4.2-windows-x64.zip`，完整解压后运行 `StillEnough.exe`；同目录包含 `stillenough-cli.exe`，附 SHA256 校验文件。

升级前从托盘退出旧版本，再解压运行新版。保留现有本地数据和系统凭据。桌面端需要 Windows 10/11 x64、Microsoft Edge WebView2 Runtime 和 VC 运行库。

## 验证边界

版本一致性、版本脚本测试 1 项、前端测试 45 项、TypeScript、ESLint 和 Vite 前端构建通过。

GUI/CLI release 构建及便携 ZIP 校验通过，包括双端版本、x64 架构、8 文件白名单和逐文件 SHA256。首次构建因运行中的目标 EXE 被占用失败，关闭该实例后重建成功。本次未重复 Rust 完整测试。

此次修复依据截图及 CSS 定位；Windows 原生窗口重新显示、焦点切换、Tab 导航和拖动后的表现仍待实测。没有新增真实账号验证范围。
