# StillEnough v0.4.3

版本更新日期：2026-10-26。当前为源码版本更新，尚未构建或发布便携包。

## 修复

- Kimi Code 支持字符串形式的 limit、used、remaining 计数，避免把可解析的额度响应报为“接口变化”。
- GLM 支持显式区分的多个 Token/Credit 额度窗口，不再因同类型的小时/周窗口同时存在而拒绝解析；不按重置先后猜周期。
- Claude Code 支持 Fable 及新版模型周额度，读取 limits 中的 percent，覆盖同模型旧窗口并排除特定使用场景的子限额。

全部 16 个渠道入口的对照范围和证据见 [渠道读取核对记录](../providers/channel-read-audit-2026-10-26.md)。保留缺失额度、无效日期、重复身份与越界值校验，不扩大真实账号验证范围。

## 验证边界

本次解析改动在升版前通过完整 Rust 工作区测试：130 项通过、7 项真实环境专项忽略；Clippy、格式检查通过。升版后版本一致性和版本脚本测试通过。尚未构建新版本 GUI/CLI 或便携 ZIP，未进行真实账号复测及 Windows 桌面交互验收。

本地编译：先从托盘退出正在运行的程序，再执行 `pnpm desktop:bundle -Bundle none`；便携打包执行 `powershell -NoProfile -File scripts/package-portable.ps1`。
