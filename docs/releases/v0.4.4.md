# StillEnough v0.4.4

发布日期：2026-10-26。

## 修复与改进

- Kimi Code 支持新格式中的会员共享月额度、Code 月额度和明确返回的 5 小时/周窗口；缺失项不补造，有效旧计数窗口优先，避免重复显示。新套餐没有周限额不再被视为必然缺项。
- 浮窗固定展示短时窗口，Code 月与共享月共用一列，每 6 秒轮换；标签与重置时间同行，降低行高。主窗口仍显示全部指标。
- 修复父界面每秒刷新导致轮换计时器反复重置的问题。悬停或键盘聚焦时暂停，鼠标点击遗留焦点不阻止轮换。
- 主窗口和浮窗百分比最多显示一位小数，整数不补 .0；不改变原始观测与告警计算。

## 验证边界

解析修改后 regional 测试 7 项、Rust Clippy 和格式检查通过。发布前完整 Rust 工作区测试 131 项通过、7 项真实环境专项忽略；完整前端测试 49 项、TypeScript、ESLint、Vite 构建、版本一致性和版本脚本测试通过。

GUI/CLI release 构建、便携 ZIP 双端版本、x64 架构、8 文件白名单及逐文件 SHA256 校验通过。下载 `StillEnough-v0.4.4-windows-x64.zip`，完整解压后运行 `StillEnough.exe`，同目录包含 `stillenough-cli.exe`；另附 SHA256SUMS.txt。

用户已反馈月额度显示，以及前版三列高度和轮换故障；最新计时修复后的 Windows 原生轮换、暂停、折叠和高 DPI 效果仍待实测。不同账号、地区、套餐和认证方式的月字段覆盖未全面验证。

本地编译：先从托盘退出旧程序，再执行 `pnpm desktop:bundle -Bundle none`；便携打包执行 `powershell -NoProfile -File scripts/package-portable.ps1`。
