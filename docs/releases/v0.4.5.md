# StillEnough v0.4.5

## 改进

- 新增默认关闭的实验性 Windows 浮窗毛玻璃，失焦时仍模糊背后内容；不主动切换窗口焦点。
- 毛玻璃支持整体不透明度和闲置淡化，使用系统圆角；改善明暗主题底色、文字对比度与悬停提示。
- 浮窗指标提示使用本地日期和分钟显示更新时间，无效时间显示未知。

## 验证边界

独立 Windows 对照实验中，用户确认失焦时背景实时模糊、与 55% 不透明度及圆角组合正常；用户确认调整后的明暗样式。正式浮窗的重启恢复、透明度切换、拖动、折叠、多屏 DPI、不同 Windows 版本、系统关闭透明效果及性能仍待验证。实验使用 Windows 未公开的窗口合成接口，兼容性可能随系统更新变化。

版本一致性、前端 53 项测试、TypeScript、ESLint、Vite 构建、Rust 格式和 Clippy 均通过；普通 Windows 环境 Rust 工作区 131 项通过、7 项真实环境专项忽略。GUI 和 CLI release 构建完成并核对版本为 0.4.5。详细记录见 [当前待办](../../TASKS.md)；未执行便携打包或发布 GitHub Release。
